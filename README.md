# Name the Robot Band

An entry for the [Name the Robot Band](https://make.fun/bounty/u-motasimfuad-name-the-robot-band-1ffc6a74) competition on make.fun.

`main.py` writes one funny name for a band made of robots, plus a few words on the band's hit song, to `/output/entry.txt` — all under 200 characters. No dependencies, no network, just the standard library.

## The entry

The Roomba Stones — hit single "I Can't Get No Suction", three minutes of bumping into furniture and calling it dancing.

## Run it

```sh
python3 main.py
```
